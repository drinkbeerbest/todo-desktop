# 待办软件

给重要的事，一点空间。

一款适合 Windows 电脑的本地待办与笔记应用。参考图片中的简洁清单，以桌面侧栏、清晰的文字层级、暖白色和少量琥珀色重新设计。

本仓库是完整桌面版的公开源码，首次启动为空白。

## 直接使用

从下方发布页下载 **Todo-1.0.2-Windows.exe**，双击运行。它是独立的免安装程序，无需另装 Node.js。适用于 Windows 10 / 11 x64。

第一次打开从空白开始，不预置待办记录或笔记。内容由你自己添加。

## 日常使用

- 所有待办统一保存，在「今天」「全部待办」「即将到来」之间切换。今天也会显示尚未完成的过期事项。
- 点击方框完成待办，方框附近绽开轻巧的彩纸礼花。条目稍作停留后归入已完成，可以展开、恢复或立即撤销。
- 点击任务文字，在右侧编辑标题、日期、时间和备注；星标让重要事项靠前。
- 在列表底部直接新增，按 Enter 添加。日期选择支持今天、明天、日历和不设日期。
- 待办无需分类。旧版的所有分类会自动合并，待办内容、日期和完成状态会完整保留。
- 笔记支持标题、正文、即时保存和搜索。
- 在设置中切换浅色、深色或跟随系统，开关完成礼花、减少动态效果或紧凑列表。
- 可启用到时提醒：应用保持运行、任务设置了日期与时间时，通过 Windows 通知提醒。关闭应用后不会后台运行。

## 数据与备份

内容默认保存在本机应用数据目录，不需要账号或网络。每次保存会保留前一个有效版本 `liubai.json.bak`；启动时主文件不可读，会尝试从完整的保存日志或备份恢复，并保留损坏原文件。对不支持原生文件替换的 Windows 目录，会自动使用兼容保存方式。

在「设置 → 数据与备份」导出或导入 JSON。导入会先验证文件，再显示确认；恢复会替换当前内容，建议先导出当前数据。

网页开发预览使用浏览器 localStorage，与桌面应用的数据分开。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 新建待办 / 笔记 | Ctrl + N |
| 全局搜索 | Ctrl + K |
| 设置 | Ctrl + , |
| 今天 / 全部待办 | Alt + 1 / Alt + 2 |
| 提交新待办 | Enter |
| 关闭当前弹窗或详情 | Esc |

## 开发

使用 Node.js 22.12 或更新版本。

```powershell
npm install
npm run desktop
```

`npm run dev` 仅开启浏览器开发预览。`npm run build` 进行 TypeScript 检查并生成前端资源。`npm run dist` 生成 Windows 免安装程序和解包后的桌面程序。

应用由 React、TypeScript、Vite 和 Motion 构建界面，以 Electron 承载独立桌面窗口。渲染进程开启隔离和沙箱，仅通过限定的预加载接口读写本地数据；窗口控件调用原生窗口接口。

## 验证

```powershell
npm test
npm run build
npm run test:desktop
node tests/packaged.mjs
```

模型测试覆盖日期边界、备份校验、任务过滤和排序。桌面测试在独立数据目录中验证实际 Electron 窗口的新增、完成礼花、撤销、编辑、搜索、笔记、主题、文件备份和重启恢复，并检查 880 × 600 与 1440 × 960 窗口。预览截图位于 `artifacts`，测试数据位于 `.test-data`。
